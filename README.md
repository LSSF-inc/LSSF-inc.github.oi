# LSSF

Site institucional da **LSSF**, utilizado como base pública para apresentação de produtos digitais e disponibilização de informações e documentos relacionados aos aplicativos desenvolvidos pela organização.

## Objetivos

O site funciona como ponto central para:

* Apresentação dos produtos e aplicativos da LSSF
* Informações institucionais
* Páginas de suporte aos produtos
* Termos de Uso
* Política de Privacidade
* Outros documentos e informações necessárias para os produtos publicados

## Produtos

### KitTask

Aplicativo Android de produtividade e gerenciamento de tarefas.

O site também é utilizado como apoio ao produto para disponibilização de informações e documentos relacionados ao aplicativo.

> O código-fonte dos produtos comerciais não é disponibilizado neste repositório.

## Estrutura

O repositório contém os arquivos responsáveis pela implementação e publicação do site institucional.
